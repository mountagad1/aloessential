# Page brief template

Copy this file to `docs/seo/content/briefs/<slug>.md` before writing or refreshing a priority page. Fill in every section; write "unknown" rather than guess.

1. **Audience and problem:** who searches, what they are trying to do.
2. **Intent and expected outcome:** informational, comparison, commercial, task. What the reader should be able to do after reading.
3. **Queries:** primary query, supporting queries and their source (Search Console row, DataForSEO volume with date, People Also Ask). Cluster ID from `research/KEYWORD_CLUSTER_MAP.csv`.
4. **SERP observations:** date fetched; the top 5 results, their page types, strengths and gaps; features (AI Overview, People Also Ask, video).
5. **Unique value:** the one thing this page offers that the top results do not.
6. **Evidence:** primary sources to use; the claims that need a source; regulatory limits (health claims, cosmetics).
7. **Outline:** sections and the question each answers. Tables, tools and examples.
8. **Visuals:** what each image explains, and its origin and licence.
9. **Links:** inbound links from existing pages (anchor and position), outbound links to related pages and sources.
10. **Conversion path:** the next useful step for the reader (related tool, article, product page only when the intent is commercial).
11. **Metadata:** title (about 60 characters), description (50 to 160 characters, tested), H1, URL (never change an existing URL without a 301 plan).
12. **Structured data:** Article, BreadcrumbList; nothing the page does not visibly show.
13. **Locales:** which markets, the local query wording, local data to adapt (foods, units, national references).
14. **Measurement:** primary metric (Search Console clicks and impressions of the cluster), baseline window, review date.
15. **Reviewer and quality gate result:** `content/EDITORIAL_QUALITY_STANDARD.md`.
