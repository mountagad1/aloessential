## Rules

- Research each market's wording and SERP before adapting, and never assume a translation carries the same demand or competition. Only the German fibre SERP has been checked so far.
- Localize the data, not only the labels: foods, portions, national references, each with its source.
- A national value goes next to the EFSA value; it never replaces it silently.
